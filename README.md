# Pattern Playground — Class 6 CBSE Maths

An interactive practice website for mathematical patterns. It is a plain HTML, CSS, and JavaScript project, so no installation or build step is needed.

## Included practice

- Natural, odd, and even number sequences
- Virahanka / Fibonacci, triangular, square, cube, powers of 2 and powers of 3
- Centered hexagonal number patterns
- Up-and-down sequences, common terms across sequences, and odd-number/square-number relationships
- Centered-hexagonal and cube-number relationships
- Koch snowflake pattern questions

## Student challenge features

- 32 mixed questions
- 60-second timer for every question
- Two attempts per question
- Hint after the first incorrect attempt
- Named student summary and recent student results

## Run locally

Open `index.html` in any modern web browser.

## Upload to GitHub

1. Create a new empty repository on GitHub.
2. Upload these files to the repository root:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `README.md`
   - `.gitignore`
3. To publish it as a website, enable **GitHub Pages** in the repository settings and select the `main` branch / root folder.

The published URL will normally be `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
